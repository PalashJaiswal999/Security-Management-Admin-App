# Security Management System – Manual QA Case Study

## Project Overview

During my QA internship, I worked on testing a Security Management System consisting of a web-based Admin Panel and a mobile application for security guards.

The system was designed to manage guard registration, training, site allocation, attendance, duty schedules, working hours, leave requests, emergency functions, and incident reporting.

My responsibilities included functional testing, end-to-end workflow validation, UI testing, negative testing, defect reporting, and retesting.

## Application Modules

### 1. Admin Panel

The Admin Panel provided administrative functionalities for managing security guards and their assigned duties.

**Key Functionalities Tested:**
- Guard Registration and Creation
- New Enrolled Guard Training Tracking
- Site Allocation to Guards
- Attendance Management
- Guard Management
- Guard Status Tracking

### 2. Mobile Application

The mobile application provided security guards with access to their duty-related information and operational functionalities.

**Key Functionalities Tested:**
- Guard Login and Authentication
- Site Updates
- Break Time Management
- Break-End Notifications
- Routine and Duty Schedule Display
- Fare Information Display
- Working Hours Display
- Leave Application
- Early Leave from Site Application
- Emergency Functions and Notifications
- Emergency Contacts
- Incident Reporting
- Photo Upload

## Testing Scope

### Functional Testing
Verified individual features to ensure they behaved as expected.

### End-to-End Testing
Validated complete workflows across the mobile application and Admin Panel.

### UI Testing
Checked interface elements, layouts, buttons, labels, and visual consistency.

### Negative Testing
Tested invalid inputs, missing information, and incorrect user actions to identify potential defects.

### Bug Reporting
Documented identified defects with reproducible steps, expected results, actual results, and supporting evidence.

### Retesting
Reverified reported defects after fixes to confirm whether the issues were resolved.
